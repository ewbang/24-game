# 凑廿四 · 24 点在线游戏

一个零依赖的 24 点网页小游戏，同时作为微信小程序「凑廿四」的推广落地页。页面为单个 `index.html`，可直接双击打开游玩，也可部署到任意静态托管服务。

## 快速开始

**直接试玩**：双击 `index.html`，或拖入浏览器。

**本地服务器**（如需验证 canonical / 社交分享标签）：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000/index.html
```

无需安装依赖、无需构建步骤。二维码图片位于 `assets/`，随页面一同部署即可。

## 玩法

从 1–13 中发出四个数字，用加、减、乘、除将它们两两合并，最终结果为 24 即获胜。每张牌必须且只能使用一次，中间结果允许出现分数。

操作方式：

1. 依次点击两张牌，再点击一个运算符，即可合并为一张新牌；
2. 减法与除法可用「交换顺序」调整先后；
3. 「撤销」可回到上一步，「重来」回到最初四个数，「换一题」直接发新牌；
4. 卡住时点「提示」，分三级给出：高亮要合并的两张牌 → 给出运算符 → 给出完整算式（每用一次扣分）。

键盘快捷键：`1`–`4` 选牌，`+` `-` `*` `/` 选运算符，`U` 撤销，`H` 提示，`R` 重来，`Esc` 清空选择。

难度说明：

| 难度 | 牌面范围 | 特点 |
|---|---|---|
| 入门 | 1–10 | 数字较小，适合熟悉规则 |
| 标准 | 1–13 | 完整牌面范围 |
| 挑战 | 1–13 | 仅发必须用除法才有解的牌面 |

## 功能特性

- **有理数运算**：所有中间结果以约分后的 `{分子, 分母}` 存储，不存在浮点误差导致的误判。`3 3 8 8`、`1 5 5 5` 等必须用分数的经典题可正常求解。
- **保证有解**：内置求解器，出题前先验证；残局无解时会主动提示撤销。
- **竖式分数**：合并出的分数以分子在上、分数线居中、分母在下的竖式呈现，负号置于分数左侧。
- **计分与连击**：基础分随用时递减，连击提供加成，提示会扣分（单题最低 30 分）。难度、音效偏好与最高分保存在 `localStorage`。
- **推广入口**：面板下方常驻推广卡，胜利弹层内设转化位；两处均可点击放大查看小程序码，并按运行环境给出识别指引（微信内长按识别／手机浏览器截图后走相册／桌面用手机微信扫一扫）。
- **SEO 友好**：可见的规则、技巧、例题与 FAQ 内容，语义化标签，`WebApplication` 与 `FAQPage` 结构化数据，完整社交分享卡片标签。

## 实现要点

**求解器** `solveAll(cards, opKeys)` 递归地两两合并牌，按表达式文本去重，返回解字符串与解树。`firstMove(tree)` 从解树中取出最早可执行的一步，驱动分步提示。同一求解器同时用于出题校验、残局检测和提示，避免逻辑分叉。

**竖式分数** `fHtml(a)` 负责展示层，整数原样输出，分数输出内联的分子／分数线／分母结构；`fStr(a)` 保留横式，用于内部表达式去重和屏幕阅读器的 `aria-label`。两者分工明确：展示用竖式，计算与读屏用横式。

**出题策略** 入门限定 1–10；挑战难度通过「仅用 `+ − ×` 是否无解」来筛出必须借助除法的牌面。

**绝对 URL 注入** 由于部署域名未知，`canonical`、`og:url`、`og:image`、`twitter:image` 由页内脚本按 `location` 在运行时注入，仅在 `http(s)` 下生效；本地 `file://` 打开时不会写入错误地址。

## 部署与 SEO

页面为纯静态资源，部署到任意静态托管（如对象存储、静态站点服务、Nginx）即可，无需服务端。

上线后建议完成以下事项：

1. 将站点部署到正式域名根目录，确认 `assets/miniprogram-qr.jpg` 可正常访问；
2. 在搜索引擎站长平台提交站点与 `sitemap.xml`；
3. 用富媒体测试工具校验结构化数据与社交分享卡片；
4. SEO 效果按月累积，当前页面解决的是"能被理解、能被索引"的前置条件。

页面未配置虚假评分数据；结构化数据中的评分字段有意省略，以免违反搜索引擎规范。
