## 24 点网页小游戏（C:/Users/admin/Desktop/24-game/index.html）

- 单文件 HTML/CSS/JS，无外部依赖，双击即玩。
- 数值层使用有理数（分数）运算，避免浮点误差；除法分母为 0 返回 null 由调用方拦截。
- 求解器 `solveAll(cards, opKeys)`：递归合并两两，返回去重后的解表达式与解树；`firstMove(tree)` 从解树取最早可执行的一步，用于分步提示。
- 出题只发有解牌面；难度三档：入门（1–10）、标准（1–13）、挑战（1–13 且必须用除法，判定方式＝仅用 +−× 无解）。
- 交互采用「点两张牌 → 点运算符」合并，支持交换顺序（减法/除法方向）、撤销、重来、三级提示、连击计分、localStorage 存难度/音效/最高分。
- 验证方式：Node 垫片跑求解器 200 手随机题（解均等于 24 且四张牌各用一次）+ 模拟 DOM 跑完整交互链路；Chrome headless 截图校验布局（注意其视口最小宽度 512px，且动画帧不推进）。
- 关键教训：入场动画若用 `opacity:0` + `fill-mode both`，在动画时钟不推进的环境下元素会永久不可见；改为纯 transform 入场更稳。
